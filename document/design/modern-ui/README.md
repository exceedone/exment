# Exment modern UI デザインサンプル

Exment の画面を「落ち着いた、すっきりした見た目」にするための見本です。
Notion のような考え方（余白を広く、色を少なく、線と影を減らす）を参考にしていますが、見た目をまねたものではありません。

## 見かた

`index.html` をブラウザーで開いてください。インターネット接続やビルドは不要です。

| ファイル | 画面 |
| --- | --- |
| `index.html` | サンプルの入口と色の一覧 |
| `login.html` | ログイン |
| `dashboard.html` | ダッシュボード |
| `data-list.html` | データ一覧（グリッド） |
| `data-form.html` | データ編集（フォーム） |

各ファイルは1つで完結しています（CSS はファイルの中に書いてあります）。画面の中のデータはすべて架空です。

## 考え方

1. **色は少なく。** 白と灰色を基本にして、色はアクセントの青1色だけにします。青は Exment の新しいロゴ（`public/images/exment_mark.svg`）と同じ系統です。
2. **余白は広く。** 項目どうしの間をあけて、枠で囲まなくてもまとまりが分かるようにします。
3. **線と影は減らす。** 影は使いません。線は「表の行の区切り」と「見出しの下」の細い線だけにします。
4. **見出しは大きさと太さで分ける。** 色や背景色では区別しません。
5. **色のついたボタンは1画面に1つ。** いちばん大事な操作（「新規」「保存」「ログイン」）だけを青にして、ほかは灰色の静かなボタンにします。

## トークン（共通の値）

名前と値は、実際のアプリ用の CSS（`public/vendor/exment/css/modern.css`）の `:root` と同じです。

## 実際のアプリでの切り替え

画面のデザインは「モダン」と「クラシック」の2つから選べます。**初期値は「モダン」です。**

- **モダン**: このサンプルの考え方で作った、白と灰色を基本にした新しいデザイン
- **クラシック**: これまでの Exment のデザイン

### 画面で切り替える

1. 管理者でログインして、メニューの「管理者設定」→「システム設定」を開きます。
2. 「サイトメニューレイアウト」の下にある **「画面のデザイン」** で「モダン」か「クラシック」を選びます。
3. 「保存」を押して、ページを再読み込みします。

アップデートしたあと、何も設定していない環境は「モダン」になります。これまでの見た目に戻したいときは、「画面のデザイン」で「クラシック」を選んで保存してください。

### サーバーの設定で固定する（.env）

`.env` に次のどちらかを書くと、サーバー側でデザインを固定できます。

```
EXMENT_UI_DESIGN=modern
EXMENT_UI_DESIGN=classic
```

- `.env` に書いた値が、画面の設定より優先されます。
- このとき、システム設定の「画面のデザイン」は選べなくなり、「（サーバーの設定で固定されています）」と表示されます。
- 書かなければ、画面の設定が使われます。
- 設定をキャッシュしている場合は `php artisan config:clear` を実行してください。

「クラシック」のときは、新しいデザイン用の CSS（`public/vendor/exment/css/modern.css`）は読み込まれません。CSS を直したあとは、ブラウザーで強制再読み込み（Ctrl + F5）をしてください。

### いま対応している画面

| 画面 | 変わるところ |
| --- | --- |
| ログイン | 背景、カード、入力欄、ボタン（パスワードリセットや2段階認証の画面も同じ見た目です） |
| ヘッダー（上の帯） | 白い帯になります。アイコンと文字は灰色、下に細い線が1本入ります |
| サイドメニュー（左） | うすい灰色の背景。いま開いているページだけ、うすい青になります |
| ダッシュボード | 緑の上線と影をやめて、細い枠1本にします。未登録の枠は点線になります |
| データ一覧 | 枠なしの表。見出しは小さな灰色の文字、しま模様なし、選んだ行はうすい青 |
| データの新規作成・編集 | 項目名は灰色の太字。入力欄は細い枠で、入力中は青い輪が出ます。タブは青い下線になります |
| 設定などのほかの画面 | 箱（ボックス）、ボタン、入力欄、タブに同じ見た目が当たります |

システム設定で選んだ「サイトカラー（スキン）」が何色でも、同じ白と灰色の見た目になります。

### 見た目を確かめるところ

次の画面を開いて、くずれがないかを見てください（URL は例です）。

1. **ログイン** `/admin/auth/login`
   - カードが白、ボタンが青になっているか。
2. **ダッシュボード** `/admin`
   - 上の帯が白く、検索欄・ヘルプ・通知・ワークフローのアイコンが見えるか。未読の数（赤い丸）が読めるか。
   - 左メニューで、いまのページだけがうすい青になっているか。親メニューを開いたとき、子メニューが読めるか。
   - 箱の上の緑の線がなくなり、細い枠になっているか。箱の右上の小さなボタンが見えるか。
   - ヘッダーにロゴ画像を設定している場合、白い背景でも見えるか（白いロゴだと見えなくなります）。
3. **サイドメニューを閉じた状態**（上の帯の左端のボタンを押す）
   - アイコンだけの細い列になり、マウスを乗せるとメニュー名と子メニューが右に出るか。出たメニューの背景が透けていないか。
4. **スマートフォンの幅**（ブラウザーの幅を 767px より狭くする）
   - 左端のボタンでメニューが横から出てくるか。ユーザーメニューや通知の文字が読めるか。
5. **データ一覧** `/admin/data/custom_value_edit_all`
   - ツールのボタンが灰色、「新規」だけが青か。列の固定や見出しの固定をしたとき、色がずれないか。
6. **新規作成** `/admin/data/custom_value_edit_all/create`、**編集** `/admin/data/custom_value_edit_all/1/edit`
   - 入力欄、選択欄（select2）、日付、ファイルの各項目がくずれていないか。
   - 読み取り専用の選択欄が灰色のままで、クリックしても開かないか。
   - 入力欄の前後に記号がつく項目（金額の「¥」など）で、角がつながって見えるか。
   - 子テーブル（明細行）の表と「新規」「削除」ボタン。
   - いちばん下の「保存」ボタンが青か。エラーのとき、枠が赤くなるか。
7. **タブのある画面** `/admin/system`（システム設定）など
   - 開いているタブに青い下線が出ているか。
8. **デザインの切り替え** `/admin/system`
   - 「画面のデザイン」を「クラシック」にして保存すると、ログイン画面も管理画面もすべて元の見た目に戻るか。「モダン」に戻すと新しい見た目になるか。
   - `.env` に `EXMENT_UI_DESIGN=classic` を書くと、画面の設定が「モダン」でも元の見た目になり、「画面のデザイン」が選べなくなって注意書きが出るか。

## まだやっていないこと

- モーダル（ポップアップ）の枠や見出し、カレンダー、カンバン、ガントなどの個別の画面
- 公開フォーム、インストール画面
- ダークモード
- アイコンの統一（線のアイコン1種類にそろえる予定です）
- 上の HTML サンプルと実際の画面は、まだ完全には同じではありません（実際の画面は、今のレイアウトをこわさないように、色・線・角の丸みを中心に変えています）
