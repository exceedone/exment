# Exment modern UI デザインサンプル

Exment の画面を「落ち着いた、すっきりした見た目」にするための見本です。
Notion のような考え方（余白を広く、色を少なく、線と影を減らす）を参考にしていますが、見た目をまねたものではありません。

## 見かた

`index.html` をブラウザーで開いてください。インターネット接続やビルドは不要です。

| ファイル | 画面 |
| --- | --- |
| `index.html` | サンプルの入口と色の一覧 |
| `login.html` | ログイン |
| `dashboard.html` | ダッシュボード |
| `data-list.html` | データ一覧（グリッド） |
| `data-form.html` | データ編集（フォーム） |

各ファイルは1つで完結しています（CSS はファイルの中に書いてあります）。画面の中のデータはすべて架空です。

## 考え方

1. **色は少なく。** 白と灰色を基本にして、色はアクセントの青1色だけにします。青は Exment の新しいロゴ（`public/images/exment_mark.svg`）と同じ系統です。
2. **余白は広く。** 項目どうしの間をあけて、枠で囲まなくてもまとまりが分かるようにします。
3. **線と影は減らす。** 影は使いません。線は「表の行の区切り」と「見出しの下」の細い線だけにします。
4. **見出しは大きさと太さで分ける。** 色や背景色では区別しません。
5. **色のついたボタンは1画面に1つ。** いちばん大事な操作（「新規」「保存」「ログイン」）だけを青にして、ほかは灰色の静かなボタンにします。

## トークン（共通の値）

名前と値は、実際のアプリ用の CSS（`public/vendor/exment/css/modern.css`）の `:root` と同じです。

### 色

| 名前 | 値 | 使いみち |
| --- | --- | --- |
| `--exm-ui-accent` | `#2563eb` | 大事なボタン、選択中のしるし |
| `--exm-ui-accent-strong` | `#1d4ed8` | リンクの文字、ボタンにマウスを乗せたとき |
| `--exm-ui-accent-soft` | `#eff4ff` | 選択した行、現在のページ番号の背景 |
| `--exm-ui-accent-ring` | `rgba(37, 99, 235, .22)` | 入力中の欄のまわりの輪 |
| `--exm-ui-text` | `#1c2024` | ふつうの文字 |
| `--exm-ui-text-sub` | `#5f6b7a` | 補助の文字、表の見出し、項目名 |
| `--exm-ui-text-faint` | `#8b95a1` | 日付、入力例など目立たせない文字 |
| `--exm-ui-bg` | `#ffffff` | ページの背景 |
| `--exm-ui-bg-sub` | `#f7f8f9` | サイドメニュー、ログイン画面の背景 |
| `--exm-ui-bg-hover` | `#f3f5f7` | マウスを乗せた行やボタン |
| `--exm-ui-line` | `#e6e8eb` | 見出しの下の線、入力欄の枠 |
| `--exm-ui-line-soft` | `#eff1f3` | 表の行の区切り線 |
| `--exm-ui-danger` | `#d1242f` | エラー、「必須」のしるし（意味を伝えるときだけ） |

ロゴのグラデーションは `#3b82f6` → `#1d4ed8` です。アクセント色はその中間の `#2563eb` にしました。白い文字を乗せても、白い背景の上に置いても、十分に読める濃さです。

### 文字

| 名前 | 値 | 使いみち |
| --- | --- | --- |
| `--exm-ui-font` | OS の標準フォント（Segoe UI、Hiragino Sans、Yu Gothic UI、Meiryo など） | すべての文字。外部のフォントは読み込みません |
| `--exm-ui-fs-xs` | 12px | 表の見出し、日付、補足 |
| `--exm-ui-fs-sm` | 13px | ボタン、項目名、説明文 |
| `--exm-ui-fs-md` | 14px | 本文、表の中身、入力欄 |
| `--exm-ui-fs-lg` | 18px | 見出し（フォームの区切りなど） |
| `--exm-ui-fs-xl` | 24px | ページのタイトル |

太さは 400（ふつう）、600（見出し・ボタン）、700（ページのタイトル）の3つだけです。

### 余白

4px を基本にした段階です。

| 名前 | 値 | 使いみち |
| --- | --- | --- |
| `--exm-ui-space-1` | 4px | ごく小さなすき間 |
| `--exm-ui-space-2` | 8px | ボタンどうしの間 |
| `--exm-ui-space-3` | 12px | 表のセルの内側 |
| `--exm-ui-space-4` | 16px | 入力欄どうしの間 |
| `--exm-ui-space-5` | 24px | フォームの項目の間、タイトルの下 |
| `--exm-ui-space-6` | 32px | ページの左右、カードの内側 |
| `--exm-ui-space-7` | 48px | まとまりとまとまりの間 |

### 形

| 名前 | 値 | 使いみち |
| --- | --- | --- |
| `--exm-ui-radius-sm` | 6px | ボタン、入力欄 |
| `--exm-ui-radius-md` | 10px | カード |

## 実際のアプリでためす

ログイン画面とデータ一覧画面だけ、実際の Exment でためせます。`.env` に次の1行を足してください。

```
EXMENT_MODERN_UI=true
```

足さなければ（初期値は `false`）、これまでの見た目のまま何も変わりません。設定をキャッシュしている場合は `php artisan config:clear` を実行してください。

## まだやっていないこと

- サイドメニュー、ヘッダー、ダッシュボード、フォームへの適用（このサンプルは見本だけです）
- ダークモード
- アイコンの統一（線のアイコン1種類にそろえる予定です。このサンプルではアイコンを使っていません）
